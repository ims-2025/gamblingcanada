# Operator logos

Each operator card shows a **real brand logo** if a raster file exists here, and
falls back to the clean SVG monogram (`<slug>.svg`) if it doesn't — so nothing
ever breaks while you fill these in.

below (PNG preferred; `.webp` or `.jpg` also work). Square logos ~240×240 look
best. Commit + push in GitHub Desktop and Vercel redeploys automatically.

## Where to get the official logos

- **Your WordPress Media Library** — the originals are already there (Media →
  search the brand → download full size).
- **Each operator's affiliate / press kit** — affiliate programs provide
  approved logo packs for exactly this use.

The `.svg` files here are the fallback monograms and can stay — they're only
shown when no matching raster logo is present.
